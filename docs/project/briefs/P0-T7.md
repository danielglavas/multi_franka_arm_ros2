### cppcheck for this package only
In `ultrasound_scan_execution/CMakeLists.txt`, inside `if(BUILD_TESTING)`:
```cmake
find_package(ament_lint_auto REQUIRED)
# cppcheck is added by hand below, so lint_auto must not add it a second time.
list(APPEND AMENT_LINT_AUTO_EXCLUDE ament_cmake_cppcheck)
ament_lint_auto_find_test_dependencies()

find_package(ament_cmake_cppcheck REQUIRED)
# Paths to check come first: INCLUDE_DIRS takes every argument after it as an include dir.
ament_cppcheck(src include test LANGUAGE c++ INCLUDE_DIRS include)
# Humble's ament_cppcheck skips cppcheck 2.x as "too slow" unless this variable is set.
# Set it for this one test only, so the franka_* baseline (cppcheck skipped) stays unchanged.
set_tests_properties(cppcheck PROPERTIES ENVIRONMENT "AMENT_CPPCHECK_ALLOW_SLOW_VERSIONS=1")
```
Keep the comments. If the explicit `ament_cppcheck` call or the property does not work as written,
stop and report; do not switch to a global setting.

## Interface
`ultrasound_scan_execution/path_fraction_check.hpp`, namespace `ultrasound_scan_execution`:
```cpp
/// True when MoveIt2's achieved Cartesian path fraction is at least the required minimum.
/// Both values are fractions of the requested path, unitless, in [0.0, 1.0].
/// Throws std::invalid_argument (message names the bad argument and its value)
/// if either value is NaN or outside [0.0, 1.0].
bool is_path_fraction_acceptable(double achieved_fraction, double minimum_fraction);
```
No topics, services, parameters or frames in this task.

## Behaviour
- `achieved_fraction >= minimum_fraction` returns true; otherwise false.
- Equal values return true (a required 1.0 is met by an achieved 1.0).
- NaN, below 0.0 or above 1.0 in either argument: `std::invalid_argument`.

# Brief P0-T6: record the test baseline

Effort: medium
Type: config. Opus runs the commands and writes the result; no code, so no subagent.

## Goal
Record which existing tests already fail on the untouched base, before we change anything. From
then on, "tests pass" means "no failure that is not in the baseline". Without this list, an old
upstream lint failure and a failure we caused look the same.

## What was checked on 2026-11-21 (before writing this brief)
- `colcon list` finds 28 packages: 26 `ament_cmake`, 2 `ament_python`
  (`franka_simple_publishers`, `tf2_publisher`).
- `BUILD_TESTING` is `ON` in all 26 CMake build caches, so the tests were built during P0-T2.
- What the tests are:
  - **Linters** in every package with an `if(BUILD_TESTING)` block. Most use `ament_lint_auto`.
    `franka_hardware`, `franka_gripper` and `franka_example_controllers` list them by hand
    (clang_format, copyright, cppcheck, flake8, lint_cmake, pep257, xmllint).
  - **pytest:** `franka_description/test/urdf_tests.py` processes `robots/panda_arm.urdf.xacro`.
    `franka_moveit_config/test/srdf_tests.py` checks the SRDF.
  - **The two Python packages:** `test_copyright.py`, `test_flake8.py`, `test_pep257.py`.
- No gtest, launch_testing or node-starting test is registered. The C++ tests under
  `mujoco_ros_pkgs` are ROS 1 (`CATKIN_ENABLE_TESTING`) and either commented out (`mujoco_ros`)
  or in packages with `COLCON_IGNORE` (`mujoco_ros_sensors`, `_laser`, `_mocap_plugin`, `_control`).
- So no test starts a node, opens MuJoCo or reaches the real robot. It is safe to run them all.
- Only `docs/`, `CLAUDE.md` and `.claude/` changed since the P0-T2 build, so the build is current.

Not checked:
- How long the run takes.
- Whether `urdf_tests.py` still finds `robots/panda_arm.urdf.xacro`, now that upstream moved the
  xacro files to `robots/common/`. The run will show it.

## Steps
1. Run all tests, two packages at a time because of the 7 GB RAM:
   `source ~/start_env.sh && cd ~/ros2_ws_3 && colcon test --parallel-workers 2`
2. Collect the results:
   `colcon test-result --all` (one line per result file) and `colcon test-result --verbose`
   (the failing test cases with their messages).
3. For each failure, read enough of the message to write a one-line cause (for example "clang-format:
   12 files differ from `.clang-format`"). Do not fix anything.
4. Write `docs/project/TEST_BASELINE.md` (contents below).
5. Close the task in `PLAN.md`: `[x]`, date, totals, change-log line.

## Create / change
- `docs/project/TEST_BASELINE.md`:
  - Date, git commit of `ultrasound`, the `mujoco_ros_pkgs` submodule commit, and the exact commands used.
  - Totals: tests, failures, errors, skipped.
  - A table with one row per package: tests, failures, and the failing test names.
  - A one-line cause for each failing test.
  - The rule: a change "passes tests" when `colcon test-result` shows no failing test missing from
    this file, and every package under `ultrasound/` has zero failures. A baseline failure that
    disappears is fine; write it down here when it happens.
  - When to re-record: after a rebase onto a newer `upstream/humble`, or a change of
    linter versions through apt.
- `docs/PLAN.md`: P0-T6 `[~]` now, `[x]` at the end, plus a change-log line.

Test output stays in `~/ros2_ws_3/build` and `log/`. It is outside the repo and is not committed.

## Done when
`docs/project/TEST_BASELINE.md` exists with the contents above, its totals match the
`colcon test-result` summary line, and `PLAN.md` refers to it.

## Result (2026-11-21)
- The run took 17 s for 28 packages. `colcon test` exited 0 because test failures do not change its exit code.
- Summary: 3268 tests, 0 errors, 2888 failures, 142 skipped. 20 packages have failures.
- The only functional failure is `franka_description_urdf_tests` (6 of 6). The path
  `robots/panda_arm.urdf.xacro` no longer exists; upstream moved the arm to `robots/real/` and `robots/sim/`.
- `franka_moveit_config_srdf_tests` passes.
- Everything else is a style linter: flake8, clang_format, uncrustify, lint_cmake, copyright.
- All 142 skips are cppcheck: `ament_cppcheck` skips cppcheck 2.7 unless `AMENT_CPPCHECK_ALLOW_SLOW_VERSIONS` is set.
- Full table and the pass rule: `docs/project/TEST_BASELINE.md`.

## Out of scope
- Fixing any failing test or linter, inside or outside `franka_*`.
- Changing `CMakeLists.txt` or linter settings.
- Rebuilding, unless `colcon test` reports a missing test executable.
